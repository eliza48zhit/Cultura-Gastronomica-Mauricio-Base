🛠️ Especificaciones Técnicas del ADN de Mauricio
Este contrato documenta la física de las masas elásticas y el equilibrio de polifenoles:

Extensibilidad de la Masa (uint256): Cuantifica la capacidad de laminado del Dholl Puri. Un valor de 98 indica una masa de leguminosas y trigo capaz de extenderse hasta espesores milimétricos sin fracturar las cadenas de gluten.

Balance de Especias (uint256): Registra el grado de integración de sabores en currys y estofados (Rougaille). Este parámetro mide la hidrólisis de las especias en medios ácidos para maximizar el perfil organoléptico.

Uso de Leguminosas (bool): Validador técnico que confirma la integración de proteínas vegetales (como el Chana Dal) directamente en la estructura de las masas de pan plano.

Gobernanza: Funciones de darLike y darDislike para la interacción de la comunidad en la red Base.
